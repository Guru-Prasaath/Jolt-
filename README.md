# Jolt - Shatter Your Mental Blocks ⚡️

**Jolt** is a high-energy, interactive iOS application built with **SwiftUI** and **SpriteKit**. It is designed to help users physically manifest and then destroy their mental barriers, providing a satisfying and haptic-rich experience to "recharge" and "shatter" doubts.

## 🚀 Features

### ⚡️ Reactor Core (The Jolt)
- **Interactive Revving**: Build up "heat" and "charge" by scrubbing the reactor core.
- **Dynamic Feedback**: Real-time particle effects (sparks), shake animations, and evolving UI colors based on charge level.
- **Haptic Integration**: Custom haptic patterns that intensify as you build up the engine.
- **System Ignition**: Reach 100% to trigger a full system ignition with a celebratory haptic and visual sequence.

### 🔨 Shatter Doubts
- **Mental Block Input**: Add custom words representing what's stopping you (e.g., "FEAR", "DOUBT", "PROCRASTINATION").
- **SpriteKit Physics**: Your mental blocks are transformed into physical "glass panes" in a 2D physics world.
- **Cinematic Destruction**: Launch projectiles to shatter the glass panes into hundreds of shards with heavy impact haptics.
- **Mind Cleared**: Once all blocks are destroyed, receive a visual confirmation that your mind is cleared.

### 💎 Premium Design
- **Glassmorphism**: Beautiful "ultra-thin material" overlays and frosted glass effects.
- **Dark Mode Aesthetic**: A sleek, high-contrast dark theme with vibrant neon accents (Indigo, Cyan, Orange).
- **Responsive Animations**: Spring-based transitions and physics-driven interactions that make the app feel alive.

## 🛠 Tech Stack
- **Swift 6.0**
- **SwiftUI**: For the main UI and interaction logic.
- **SpriteKit**: For the glass-shattering physics engine.
- **Core Haptics**: For deep, tactile feedback.

## 📱 Requirements
- **iOS 16.0+**
- **Swift Playgrounds / Xcode**

## 🏁 How to Run
1. Open `Jolt.swiftpm` in **Swift Playgrounds** on iPad/Mac or **Xcode**.
2. Run the project on an iOS device (recommended for haptics) or Simulator.
3. Navigate between the "Jolt" core and "Shatter" module using the custom navigation.
